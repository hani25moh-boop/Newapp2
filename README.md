# Field Report V2

Offline-first Android field data entry app based on PM-EXCH-001 v2.0. It imports the reference sheets from the project Excel template, provides role-based forms, stores data locally, and exports a portable Excel workbook.

## Current V2 scope
- Role picker for project, site, warehouse, discipline, QA/QC, safety, finance, and procurement users.
- Lightweight XLSX import for `Ref_Projects`, `Ref_People`, `Ref_Tasks`, `Ref_WorkItems`, and `Ref_Materials`.
- Quantity-entry form for site/electrical/mechanical roles.
- Material movement form for warehouse users.
- Local Room database and Excel sharing.
