# Field Report V3

نسخة موحدة وخفيفة لتطبيق إدخال بيانات المشاريع ميدانيًا.

- ملف الاستيراد والتصدير يستخدمان نفس الأعمدة.
- أوراق القالب البسيط: `Projects`, `Items`, `Entries`.
- كل سجل يحفظ الدور، نوع السجل، المشروع، البند، الكمية، اسم/كود المدخل، والتاريخ والوقت بالدقيقة.
- الأقسام مدعومة من نفس الواجهة: الموقع، المخازن، الكهرباء، الميكانيك، الجودة، السلامة، المالية، المشتريات، ومدير المشروع.
- السجل يظهر أسفل النموذج فور الحفظ للمراجعة قبل التصدير.
